# Static website assets

Edit the readable `.js` / `.css` sources, then run `node tools/build_assets.cjs` before publishing. HTML loads the generated `.min.js` / `.min.css` files. Keep both source and generated files in Git. Do not edit the generated files directly.

The build uses the official Terser 5.51.2 browser bundle, stored outside Git at `.workbuddy/build-tools/terser.min.js`. Download it from `https://cdn.jsdelivr.net/npm/terser@5.51.2/dist/bundle.min.js` if missing. Terser is a build tool only; visitors do not download it. CSS compaction preserves declaration order, selector spaces, strings and calc operator spacing.

Fixed Material tokens are generated by `node tools/build_theme.cjs` using the unmodified `libs.js`. Change palette definitions in that builder, rebuild `theme-tokens.js`, and verify light/dark colors. The browser loads the small token file instead of the MCU calculation library.

Chinese copy changes require rebuilding `fonts/build_jinshu.py` with the official OTF sources. The homepage and shared text form the main font subsets; tutorial-only characters are separate `-guide` subsets and download only when used. Comments do not form part of the glyph set.

Source Serif 4 keeps variable optical sizing (8–60) and the website's 400–500 weights. Rebuild with `fonts/build_latin.py --source <official-variable-woff2>`. Licenses are in `fonts/`.

The hero images retain 2522×1410 pixels and the original crop. `image.avif` is the primary image, `image.webp` the fallback. After replacing the photo, update both formats, the baked `image-blur.webp`, its static bottom-row extension `image-blur-edge.svg`, and image URLs/preloads together. Current blur assets remain unchanged because only image encoding changed.

Cache bust only changed assets: compressed fonts use v140, the photo uses v140, unchanged blur assets keep v106 / v138. Future CSS/JS changes need a new HTML asset version and a rebuild; do not bump unchanged font binary URLs unnecessarily.
