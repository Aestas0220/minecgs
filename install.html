01

mrpack 是什么？

它是一份进服安装包，包含进入 MineCGS 服务器需要的模组、配置和服务器链接。启动器会按包里的清单下载并安装所需文件。

不用解压，也不用自己逐个装模组。把 .mrpack 文件拖进支持它的 HMCL、PCL2 等启动器，就能开始安装。

本教程面向 Windows / macOS 电脑上的 Minecraft Java 版；手机和 iPad 不能按这套步骤安装。已有启动器？直接看第 04 步。
02

下载 HMCL

启动器就是用来安装和打开 Minecraft 的工具。第一次使用，推荐先用 HMCL。

HMCL 官网 ↗ 打开官方下载页 ↗
  1. 打开下载页，选择“稳定版”，再选择与你电脑对应的 Windows 或 Mac 下载项。
  2. Windows 用户下载 .exe 文件。新建一个容易找到的文件夹（例如 MineCGS），把启动器放进去，再双击打开。
  3. Mac 用户选择 Mac 下载项，按下载说明打开。启动器提示缺少 Java 时，继续下一步。
03

安装 Java 25

Java 是运行 Minecraft 的基础环境。本进服包使用 Java 25；它和启动器是两个不同的东西。

下载 Zulu JRE 25 ↗
  1. 在下载页选择 Java 25 (LTS)、你的系统，以及 JRE。大多数 Windows 电脑选择 x86 64-bit；Windows ARM 电脑选择 ARM 64-bit。
  2. Windows 优先下载 .msi，双击后按提示完成安装，再重新打开 HMCL。
  3. Mac 的 Apple 芯片（M 系列）选 ARM 64-bit，Intel 芯片选 x86 64-bit。若下载的是 .zip，解压到固定文件夹。
  4. 如果启动器没有自动找到 Java，在该版本的设置中选择 Java 25；需要手动指定时，找到安装目录里的 bin/javaw.exe（Windows）或 bin/java（Mac）。
某些系统只提供 JDK 25，也可以使用。Mac 的 Java 可能位于解压文件夹中的 Contents/Home/bin。
04

导入进服包

  1. 回官网点击“下载进服包”，阅读须知并确认，保存 minecgs-modpack.mrpack。
  2. 打开 HMCL，把这个文件从文件夹拖到启动器主界面。使用 PCL2 时，也可尝试拖入主界面；请使用支持 mrpack 的新版。
  3. 出现安装窗口后，给它取一个名称（例如 MineCGS），点击安装，等待下载完成。
  4. 如果拖动没有反应，在启动器里找“导入整合包”或“安装整合包”，手动选择这个 .mrpack 文件。
返回官网下载进服包 →
05

启动并进入服务器

  1. 在启动器中登录你的 Minecraft 账号，选中刚安装的 MineCGS 版本，再点击启动。
  2. 进入主界面后打开多人服务器列表，找到进服包预置的 MineCGS 服务器，点击连接。
  3. 如果列表为空、连接失败或提示没有权限，把提示截图发给我们。

06

卡住了？

提示 Java 不兼容

检查 MineCGS 这个版本是否选中了 Java 25，而不是旧的 Java 8、17 或 21。

文件被当成压缩包打开

关闭解压软件，回到文件所在的文件夹，把文件拖进启动器。不要修改 .mrpack 后缀。

下载失败或启动后报错

先检查网络，再重试。仍然失败时，保留启动器的报错或日志，连同截图发给项目成员。
